# 🔗 Trello API Testing (Postman)

## 🚀 About Project
This project focuses on API testing of Trello using Postman. It covers CRUD operations like create, update, get, and delete boards, ensuring proper API functionality.

## 🛠 Tech Stack
- Postman  
- REST API  
- JavaScript (Postman Scripts)  

## ⚙️ Features
- Create, update, get, and delete board APIs  
- Response validation using test scripts  
- Status code validation  
- Use of environment variables for dynamic data  
- JSON response handling  

## 🔍 Key Functionalities Tested
- Create Board (POST)  
- Update Board (PUT)  
- Get Board / Lists (GET)  
- Delete Board (DELETE)  

## ▶️ How to Run
1. Open Postman  
2. Import the collection  
3. Add API key and token  
4. Run the requests
